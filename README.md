# RollCraft

2D로 그린 단면을 회전시켜 만든 3D 물체(회전체)를 굴려 장애물 코스를 통과하는 퍼즐 러너입니다.
같은 장애물이라도 **어떤 모양을 그렸느냐에 따라 결과가 달라지고**, 코스 중간의 변신 작업대에서 모양을 바꿔 가며 풉니다.

컴퓨터그래픽스 텀프로젝트 · Team J (원유승 · 최수정 · 손연우)

## 실행

Node.js **20.19 이상**이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 <http://localhost:5173/>을 엽니다.

| 명령              | 설명                           |
| ----------------- | ------------------------------ |
| `npm run dev`     | 개발 서버 (수정하면 바로 반영) |
| `npm run build`   | 배포용 빌드 → `dist/`          |
| `npm run preview` | 빌드 결과를 로컬에서 확인      |
| `npm run format`  | Prettier로 코드 포맷 맞추기    |

## 조작

**모양 만들기 (에디터)**

| 입력                | 동작                                 |
| ------------------- | ------------------------------------ |
| 마우스 드래그       | 단면 그리기, 제어점 12개 직접 옮기기 |
| 프리셋 버튼         | 구 · 원통 · 아령                     |
| 분할 수 슬라이더    | 회전체 메쉬의 원주 분할 수 (8 ~ 64)  |
| `Ctrl` + `Z`        | 실행 취소                            |
| `Enter` / 확정 버튼 | 이 모양으로 코스 달리기              |

**주행**

| 키                | 동작                                            |
| ----------------- | ----------------------------------------------- |
| `W` / `S` (↑ / ↓) | 앞으로 / 뒤로 구르기                            |
| `A` / `D` (← / →) | 조향                                            |
| `R`               | 처음부터 다시                                   |
| `E`               | 모양 설정 화면으로 (클리어 · 게임오버 화면에서) |
| `F`               | 변신 작업대 열기 (빛나는 패드 위에서만)         |
| `Esc`             | 변신 작업대 취소 (작업대 화면의 취소 버튼)      |

## 코스 (level1, 약 150m)

세 부분으로 나뉘고, 부분마다 유리한 모양이 다릅니다. 사이사이 작업대에서 모양을 바꿔 가며 풉니다.

| 부분 | 구간                                                          | 유리한 모양 |
| ---- | ------------------------------------------------------------- | ----------- |
| 1부  | 분할 레일 → 작업대 A → 곡선(벽) → 불규칙 계단 → 급커브(왼쪽)  | 구          |
| 2부  | 작업대 B → 강풍 → 분할 레일 2                                 | 원통        |
| 3부  | 작업대 C → 곡선 2(벽) → 불규칙 계단 2 → 급커브 2(오른쪽) → 골 | 구          |

| 구간        | 통과하기 좋은 모양                    | 실패하는 경우                                           |
| ----------- | ------------------------------------- | ------------------------------------------------------- |
| 분할 레일   | 축 방향으로 틈을 걸치는 모양          | 짧고 넓은 원반은 틈으로 낙하                            |
| 곡선 (벽)   | 구 (어느 방향으로나 구름)             | 원통 · 아령은 벽에 붙어 멈춤                            |
| 불규칙 계단 | 반지름이 큰 모양 (구)                 | 반지름이 작으면 턱에 걸림                               |
| 급커브      | 아령은 조향만으로, 구는 감속하면 통과 | 원통은 직진하다 바깥으로 낙하 (벽 없음)                 |
| 강풍        | 바람 쪽 면적이 작은 모양 (원통)       | 구 · 아령은 거의 완벽하게 A/D로 버티지 않으면 밀려 낙하 |
| 작업대      | 패드 위에서 F → 모양 바꾸기 (선택)    |                                                         |

작업대는 그냥 지나가도 되고, 패드 위에서 `F`를 누를 때만 멈추고 변신 화면이 열립니다. 변신하면 그 자리에서 속도 0으로 다시 출발합니다.

프리셋으로 풀 때: 작업대 A에서 **구** → B에서 **원통** → C에서 **구**. 헤드리스로 프리셋 조합 27가지를 돌려 보면 이 조합만 완주합니다 (약 42초).

직접 그린 모양으로 풀 때: 가운데가 넓고 양 끝이 가는 **럭비공** 모양은 작업대 없이 한 번에 완주합니다 (플레이 테스트 약 59초). 프리셋 하나로는 안 되는 코스를 잘 그린 모양 하나로 통과하는 것이 이 게임의 핵심입니다.

## 기술 스택

- [three.js](https://threejs.org/) — 렌더링. 회전체 메쉬(정점 · 법선 · 캡)는 `BufferGeometry`로 직접 생성
- [cannon-es](https://github.com/pmndrs/cannon-es) — 물리 엔진 (교수님 사용 허가). 프로파일을 원뿔대(frustum) 여러 개로 나눈 복합 콜라이더, 무게중심 · 관성은 직접 계산
- [Vite](https://vite.dev/) — 개발 서버 · 빌드
- 순수 JavaScript (ES modules), 프레임워크 없음

## 폴더 구조

```
rollcraft/
├─ index.html              컨테이너 div만 둠 (#game, #ui, #editor)
├─ src/
│  ├─ main.js              상태머신 EDIT → PLAY → CLEAR / OVER, 키 입력, 변신 작업대 연결
│  ├─ shared/              공용 계약 (contracts.js, events.js), 프리셋, 프로파일 계산 (부피 · 무게중심 · 투영면적)
│  ├─ editor/              2D 단면 에디터, 회전체 메쉬 생성 (latheGeometry.js), 3D 미리보기
│  ├─ render/              조명 · 실시간 그림자, 재질, 배경
│  ├─ ui/                  HUD, 클리어 / 게임오버, 변신 작업대 오버레이
│  ├─ physics/             물리 월드, 플레이어 콜라이더 · 조작, 골 / 낙하 판정, 콜라이더 디버그 뷰
│  │  └─ spike/            헤드리스 검증 스크립트 (node로 실행)
│  └─ stage/               트랙 (track.js), 카메라 추적 (cameraFollow.js), 레벨, 장애물
│     ├─ levels/level1.js  코스 배치 (트랙 조각 + 장애물 위치)
│     └─ obstacles/        splitRail · steps · curve · windGap · workbench (파일 하나 = 장애물 하나)
├─ progress/               사람별 진행 기록
├─ AGENTS.md, TeamRules.md 팀 규칙 · AI 작업 지침
└─ package.json, vite.config.js, .prettierrc, .editorconfig
```

## 모듈 단독 실행

`npm run dev` 후 아래 주소로 모듈만 따로 띄울 수 있습니다.

| 주소                    | 내용                                                                              |
| ----------------------- | --------------------------------------------------------------------------------- |
| `/src/editor/dev.html`  | 단면 에디터 + 3D 미리보기                                                         |
| `/src/physics/dev.html` | 물리 시험장. `1`~`3` 프리셋, `C` 콜라이더 와이어프레임, `M` 메쉬 숨기기, `R` 리셋 |
| `/src/stage/dev.html`   | 코스 전체를 위에서 내려다보기 (트랙 중심선 노란 선)                               |

헤드리스 검증 (브라우저 없이 물리만):

```bash
node src/physics/spike/frustumSpike.mjs
```

```bash
node src/physics/spike/stageRun.mjs
```

```bash
node src/physics/spike/windRun.mjs
```
